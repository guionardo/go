    **Step 1 — Change `New` return type:** Update `func New[K comparable, V any](opts ...Option)` return type from `cache.Cache[K, V]` to `cache.BatchCache[K, V]`.

    **Step 2 — Add `"errors"` import:** Add `"errors"` to the import block (needed for `errors.Join` in MSetFunc and MDelFunc). Place after `"fmt"`.

    **Step 3 — Add MGetFunc (GetMulti per D-08):** Following PATTERNS.md lines 499-537:
    - Convert keys to strings: `keysStr[i] = fmt.Sprint(k)` for each key
    - Create goroutine channel with result struct `{items map[string]*memcache.Item, err error}`
    - Goroutine: call `c.client.GetMulti(keysStr)` and send to channel
    - Select on ctx.Done() (return nil) or channel result
    - Pre-allocate result map with `len(keys)` capacity
    - Iterate `keys` in original ORDER, look up each `keysStr[i]` in `r.items` (Pitfall 1 fix)
    - If item found, `json.Unmarshal(item.Value, &value)`, add to result; skip on error
    - Silently skip missing keys and deserialization errors (D-06 best-effort)
    - Return result map

    **Step 4 — Add MSetFunc (per-key goroutines):** Following PATTERNS.md lines 540-581:
    - Create buffered channel for results: `make(chan error, len(items))`
    - Resolve TTL once with `c.resolveTTL(ttl...)`
    - Iterate `items`, launch goroutine per key-value pair
    - Each goroutine: `json.Marshal(v)`, build `memcache.Item`, call `c.client.Set(item)`, send error to channel
    - Accumulate errors in select loop; return `errors.Join(errs...)` at end
    - On ctx.Done() during accumulation: return `fmt.Errorf("cache/memcache: %w", ctx.Err())`

    **Step 5 — Add MDelFunc (per-key goroutines):** Following PATTERNS.md lines 584-615:
    - Create buffered channel. Iterate keys, launch goroutine per key
    - Each goroutine: call `c.client.Delete(fmt.Sprint(k))`, if `err == memcache.ErrCacheMiss` then send nil (idempotent)
    - Same select loop for error accumulation; return `errors.Join(errs...)`

    Per D-08 (GetMulti for MGet), D-06 (error accumulation via errors.Join).
