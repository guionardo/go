    ```go
    // BatchCache extends Cache with batch operations for multiple keys.
    // Implementations: concreteCache (returned by NewConcreteCache).
    // Existing Cache[K,V] implementors are unaffected per D-02.
    type BatchCache[K comparable, V any] interface {
        Cache[K, V]

        // MGet retrieves values for multiple keys. Only found keys are included
        // in the result map; missing keys are silently absent (D-03).
        MGet(ctx context.Context, keys ...K) map[K]V

        // MSet stores multiple key-value pairs with an optional single TTL (D-04).
        // If ttl is empty, each key uses the provider-level default TTL.
        MSet(ctx context.Context, items map[K]V, ttl ...time.Duration) error

        // MDel removes multiple keys. Idempotent — deleting already-missing
        // keys is not an error (D-05).
        MDel(ctx context.Context, keys ...K) error
    }
    ```

    Append this to cache/cache.go after the Cache interface closing brace. No new imports needed (context and time already imported).

    **Step 2 — concrete_cache.go:** Add three methods to the `cacher[K comparable, V any]` interface after `CloseFunc() error`, following PATTERNS.md lines 46-50:

    ```go
    MGetFunc(ctx context.Context, keys ...K) map[K]V
    MSetFunc(ctx context.Context, items map[K]V, ttl ...time.Duration) error
    MDelFunc(ctx context.Context, keys ...K) error
    ```

    **Step 3 — concrete_cache.go:** Change `NewConcreteCache` return type from `Cache[K, V]` to `BatchCache[K, V]`:

    ```go
    func NewConcreteCache[K comparable, V any](c cacher[K, V]) BatchCache[K, V] {
        return &concreteCache[K, V]{
            cache: c,
        }
    }

    This is backward-compatible: `BatchCache[K,V]` embeds `Cache[K,V]`, so all existing code assigning to `Cache[K,V]` continues to compile.

    func (c *concreteCache[K, V]) MSet(ctx context.Context, items map[K]V, ttl ...time.Duration) error {
        return c.cache.MSetFunc(ctx, items, ttl...)
    }
    func (c *concreteCache[K, V]) MDel(ctx context.Context, keys ...K) error {
        return c.cache.MDelFunc(ctx, keys...)
    }
    ```

    Place these after the existing `Close()` method (after line 62) and before the file end. Do NOT add any new imports — `context` and `time` are already imported in both files.
