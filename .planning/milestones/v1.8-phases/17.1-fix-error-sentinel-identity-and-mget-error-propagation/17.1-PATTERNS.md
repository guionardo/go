### 1. `cache/sqlite/sqlite.go` (error boundary, request-response)

**Analog:** the same file — the miss sentinel is already wrapped exactly the way D-01 requires.

**Current sentinel block** (`:41-54`) — D-01 changes `ErrClosed` only:

```go
// cacheDirPerm is the permission mode for cache directories.
const cacheDirPerm = 0o700

var (
	// ErrClosed is returned by operations attempted on a closed cache.
	ErrClosed = errors.New("cache/sqlite: cache is closed")

	// ErrInvalidPath is returned when a path or cache name fails validation.
	ErrInvalidPath = errors.New("cache/sqlite: invalid path")

	logger = sync.OnceValue[*slog.Logger](func() *slog.Logger {
		return slog.With(slog.String("module", "cache/sqlite"))
	})
)
```

**Wrap-a-cache-level-sentinel pattern to copy — `GetFunc`, `:200-203`:**

```go
	err := c.db.QueryRowContext(ctx, SelectSQL, fmt.Sprint(key), time.Now().UnixNano()).Scan(&data)
	if errors.Is(err, sql.ErrNoRows) {
		return zero, fmt.Errorf("cache/sqlite: %w", cache.ErrMiss)
	}
```

This is the whole of D-01's shape: `fmt.Errorf("cache/sqlite: %w", cache.ErrMiss)` → `cache/sqlite: cache: key not found`. The closed sentinel becomes the identical construction over `cache.ErrClosed`, which is why D-05's double token is "house style" rather than an accident. Note it requires the `cache` import — already present (`:18`), alongside `errors`/`fmt` (`:7`, `:8`).

**Guard being fixed — `check()`, `:175-187`:**

```go
// check returns the deferred open/validation error, or ErrClosed once the
// cache has been closed. It is the first statement of every operation.
func (c *sqliteCache[K, V]) check() error {
	if c.initErr != nil {
		return fmt.Errorf("cache/sqlite: %w", c.initErr)
	}

	if c.closed.Load() {
		return fmt.Errorf("cache/sqlite: %w", ErrClosed)
	}

	return nil
}
```

Both branches are the bug: `initErr` for a bad path is already `fmt.Errorf("%w: path must not contain '?' or '#'", ErrInvalidPath)` (`dsn.go:49`), and `ErrClosed` under D-01 will be pre-prefixed too — so both wrap once too many. `check()` is genuinely a single seam: every `*Func` in `sqlite.go` (`:194`, `:221`, `:246`) and `batch.go` (`:77`, `:150`, `:216`) calls it first, so no per-operation edits are needed.

**Twin doc site the planner must include (not listed as its own row in CONTEXT but named by D-08):** `New`'s doc comment, `:56-61`:

```go
// New creates a new SQLite cache provider with optional functional options.
//
// New never fails: open or validation errors are recorded and deferred, and
// the first operation that needs the database returns them wrapped. Returns a
// cache.BatchCache sharing the in-memory singleflight GetOrSet; the returned
// value also implements Optimizable (type-assert to reach Checkpoint/Vacuum).
```

The repo duplicates contract prose between the package doc and the constructor doc — both must be corrected in the same change or the drift the audit found simply moves.

### 2. `cache/sqlite/batch.go` (provider, batch)

**Analog:** same file, `mgetChunk`, `:110-115` — identical call shape, one level lower.

**Branch to change — `MGetFunc`, `:68-90` (D-09: `Warn` → `Error`):**

```go
// MGetFunc retrieves values for multiple keys, skipping missing or errored
// keys. It issues one chunked IN-list query per 100 deduplicated keys; expired
// rows are absent by the SQL predicate and undecodable rows are skipped at
// debug. A failed chunk is logged and skipped — remaining chunks still run
// (D-03; the frozen signature has no error channel, so a canceled context
// yields partial results by contract).
func (c *sqliteCache[K, V]) MGetFunc(ctx context.Context, keys ...K) map[K]V {
	result := make(map[K]V, len(keys))

	if err := c.check(); err != nil {
		logger().Warn("cache/sqlite: batch get skipped", "error", err)

		return result
	}
```

**Log-call analog** (`:110-115`):

```go
	rows, err := c.db.QueryContext(ctx, fmt.Sprintf(MGetSelectSQL, inPlaceholders(len(chunk))), args...)
	if err != nil {
		logger().Warn("cache/sqlite: batch get chunk failed", "keys", len(chunk), "error", err)

		return
	}
```

Established log-call conventions, all of which the D-09 edit keeps: `logger().<Level>(message, key, value [, key, value])`, message prefixed with the literal `"cache/sqlite: "` even though the logger already carries `slog.String("module", "cache/sqlite")` (`sqlite.go:51-53`), structured `"error", err` rather than formatting into the string, and a blank line between the log and the following `return` (wsl_v5 spacing rule — the repo is strict about this everywhere).

**Behaviour to preserve (do not touch):** the empty-map return, the `make(map[K]V, len(keys))` pre-allocation, and D-03's chunk-skip policy. Existing test `batch_internal_test.go:186-196` ("closed_provider_returns_empty_map") pins the closed path and stays green.

## Shared Patterns

### Sentinel wrapping — `%w`, provider prefix exactly once at the boundary
**Source:** `cache/sqlite/sqlite.go:202` (miss), `:206`/`:211` (driver/JSON), `batch.go:163`/`:186`/`:193`/`:200`/`:205`/`:228`
**Apply to:** all W1 edits in `cache/sqlite`

```go
return fmt.Errorf("cache/sqlite: %w", cache.ErrMiss)   // sqlite.go:202
return fmt.Errorf("cache/sqlite: %w", err)             // sqlite.go:206
```

Every provider error leaves the package with the literal `cache/sqlite: ` prefix and `%w` so `errors.Is`/`errors.As` reach through. The provider adds the prefix *at its own boundary* (`.planning/codebase/CONVENTIONS.md:130-137`). W1's contract is the corollary: an error that already carries the prefix must not get a second one.

### testify split: `require` for errors, `assert` for values
**Source:** `cache/sqlite/sqlite_test.go:694-703`, `sqlite_internal_test.go:600-611`
**Apply to:** all new/strengthened tests

```go
require.Error(t, err)
require.ErrorIs(t, err, cache.ErrClosed)
require.NotErrorIs(t, err, cache.ErrMiss)
require.ErrorContains(t, err, "cache/sqlite:")
assert.Equal(t, "v", got)
```

### `t.Parallel()` by default, `//nolint:paralleltest` for global state
**Source (nolint form):** `config/config_test.go:444-448`, `config/profile/profile_test.go:151-153`, `config/environment/environment_test.go:83`
**Apply to:** every new test except W5's env-isolating one

```go

func TestNewProvider_SingleFileConfiguration(t *testing.T) {
	t.Chdir(t.TempDir())
	t.Setenv("TESTCFG_NAME", "")

```

This is the repo's exact escape hatch and comment wording for tests that mutate process-global state. **`t.Setenv` panics inside a parallel test**, so W5's test must *not* call `t.Parallel()` and *must* carry this nolint with a matching reason (e.g. `// global state mutation: HOME/XDG_CACHE_HOME via t.Setenv`). ## No Analog Found

Mechanism-level gaps. The planner should specify these directly rather than point at an analog; the surrounding style still comes from the excerpts above.

| Concern | File | Role | Data Flow | Reason / recommended shape |
|---|---|---|---|---|
| Wrap-once discrimination in `check()` | `cache/sqlite/sqlite.go:177-187` | error boundary | request-response | No helper of this kind exists in the repo (`grep` for `isPrefixed`/`wrapOnce`/`strings.HasPrefix(err` returns nothing), and no provider code calls `errors.Is` on its *own* sentinels. The two candidate mechanisms both fit house style: (a) sentinel-aware switch — `errors.Is(c.initErr, ErrInvalidPath)` → return `c.initErr` unwrapped, else `fmt.Errorf("cache/sqlite: %w", c.initErr)`; (b) `wrapOnce(err)` helper using `strings.HasPrefix(err.Error(), "cache/sqlite:")`. (a) is the stronger contract (it keys on error identity, not message text) and matches the repo's `errors.Is`-first habits; (b) is broader but stringly. `ErrClosed` needs no branch at all — it is pre-prefixed by construction and can be returned as-is. |
| Full-message / single-token assertions | `cache/sqlite/sqlite_test.go:694-703` | test | request-response | No test in the repo asserts an exact error string or a token count — every assertion is `ErrorContains` (`assert.Contains(t, err.Error(), ...)` at `dsn_internal_test.go:97` and `cache/valkey/valkey_test.go:52` is the loosest precedent). Because the double token is *concatenated*, `ErrorContains` cannot detect it. Recommended: `require.Equal(t, "cache/sqlite: cache: cache is closed", err.Error())` for the contract, optionally plus `assert.Equal(t, 1, strings.Count(err.Error(), "cache/sqlite:"))` as the mechanism-independent guard. `strings` is not yet imported in `sqlite_test.go`. |
| End-to-end `New(WithName(...))` with the real `os.UserCacheDir` | new test (W5) | test | file I/O | Nothing in the repo mutates the cache-dir env: `resolveLocation` takes a `userCacheDir` seam and every test injects a fake (`dsn_internal_test.go:85-108`, `:137-139`); the only env-mutating tests mutate the *working directory* (`t.Chdir`, `config/config_test.go:446`). W5 must therefore drive the *production* seam, which means `t.Setenv` on all three variables that `os.UserCacheDir` consults: `XDG_CACHE_HOME` (linux), `HOME` (darwin), `LocalAppData` (windows) — each pointed at one `t.TempDir()`.
