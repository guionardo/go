## Decisions Made

- **`WithMemory()` over `WithName`/`WithPath` for the conformance row** (D-12): no host state, no `t.TempDir()` plumbing, and — critically — no option that could leave a deferred error on the handle, since `sqlite.New` never returns one and a broken row would produce 17 obscurely failing subtests rather than a clear message.
- **`require.Contains(t, cacheDir, root)` placed before the first `New`**: the isolation check has to precede any cache construction, otherwise a mis-set environment writes into a real cache directory *before* the test notices.
- **Comment wording follows the file's own markers** rather than paraphrasing: "always run" and "gated by skipIfNoDocker" are literal phrases from the two `// ---- … ----` section comments, keeping the doc claim and the code signpost mutually checkable.
- **Consts merged into one parenthesized block**: `decorder` (enabled in `.golangci.yml`) rejects multiple top-level `const` declarations — a lint-driven deviation from the plan's "near `closedMessage`", with identical semantics.
- **`wantDirPerm` named rather than inlined**: `mnd` would flag a bare `0o700` in the assertion, and the const documents the contract it pins.
