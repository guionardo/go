<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test -> host filesystem | The `WithName` test exercises the production `os.UserCacheDir()` seam, so a mis-set environment variable writes into the developer's or runner's real cache directory |
| test -> process-global environment | `t.Setenv` mutates `XDG_CACHE_HOME`/`HOME`/`LocalAppData` for the whole process while the test runs; a parallel test reading them concurrently is a data race |
| conformance harness -> assertion authority | A conformance row built on a handle that carries a deferred error would make every shared subtest fail (or, with a skip, pass falsely) without exercising sqlite at all |
| benchmark comment -> operator expectation | The doc comment is the only description of what the benchmark measures; a stale one silently misleads |
