Loop states: (1) skipDelim — multi-line string delimiter (`"""` or `'''`) open: a line containing the delimiter closes it, otherwise the line is skipped entirely (no header, no keyval parsing); (2) skipClose — bracket-skip rune (`]` for arrays, `}` for inline tables): a line containing that rune closes it, otherwise skipped; (3) header detection: a trimmed line starting with `[[` is an array-of-tables header — active section becomes the content between the first `[[` and the first `]]`; a line starting with `[` (but not `[[`) is a table header — active section becomes the content between the first `[` and the first `]` (D-disc-8: trailing `# comment` and inner padding `[ project ]` handled by construction; TrimSpace the inner content; quoted header segments and inner-dot-space forms are documented non-matches, A3). Header matching is EXACT string equality against the requested section — never prefix matching (P2). (4) keyval parsing: only when the active section equals the requested section AND the line contains "="; split at the FIRST "="; key side trimmed; validate the key FIRST (anti-pattern: naive SplitN before key validation — a quoted key may contain "="): bare key must match [A-Za-z0-9_-]+ and contain no "." (a "." is a dotted key → never stored), quoted key `"…"`/`'…'` strips its outer quotes; only the exact names name/version/description are stored, all other keys ignored. Value classification (strict-degrade, in order): starts with `"""` or `'''` → enter the multi-line skip state, key NOT stored; starts with `[` → array: enter bracket-skip state when no `]` on the line, key NOT stored either way; starts with `{` → inline table: enter bracket-skip state when no `}` on the line, key NOT stored either way; starts with `"` (basic string) → scan to the closing `"` honoring `\` escapes (skip the character after a backslash), value = the raw interior (NO unescaping, D-disc-5), and the remainder after the closing quote must be whitespace or the start of a `#` comment — otherwise the key is NOT stored (D-disc-6); starts with `'` (literal string) → scan to the closing `'` (no escape handling), same remainder rule; anything else (unquoted scalars, empty value) → NOT stored. Duplicate keys: last occurrence wins (A5).
