## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| time source -> expiry predicate | Wall-clock comparison decides visibility of cached data; a divergent or drift-prone time expression would resurrect or hide entries |
| sweep goroutine -> cache operations | Background maintenance shares the single pinned connection with foreground operations |
| last-connection close -> on-disk state | Sidecar removal and checkpoint decide whether committed transactions survive a restart |
