<objective>
Close UAT gap G-16-1: remove the Windows-only partial-download leak in `release/update.go` that turned PR #48's windows-latest leg red (TestDownloadUpdate_DigestMismatch at update_test.go:489) and cascade-skipped the SQLite two-process E2E and race steps — then pin the fix with a deterministic cross-platform regression test.

Purpose: the root cause is fully diagnosed (`.planning/debug/ci-two-process-e2e-windows-failure.md`): `DownloadUpdate`'s error branch calls `os.Remove(filePath)` while the `os.Create` handle is still open (the deferred `f.Close()` runs only on return) and discards the remove error. Windows denies deleting an open handle (Go's sharemode lacks FILE_SHARE_DELETE), so the 0-byte partial file survives; POSIX unlink-of-open-file semantics hid the defect locally. The fix is the mirror of the repo's own correct close-then-remove idiom in `self_update.go:187-190`, and the cleanup failure becomes observable instead of silent (UAT missing items 1 and 2).
Output: `release/update.go` fixed error path + test seam, `release/update_test.go` new regression test.
</objective>
