    Add three methods to `*memcacheCache[K, V]` following PATTERNS.md lines 499-615:

    **MGetFunc (GetMulti per D-08, lines 499-537):**
    - Convert keys to strings: `keysStr[i] = fmt.Sprint(k)` for each key
    - Create goroutine channel with result struct `{items map[string]*memcache.Item, err error}`
    - Goroutine: call `c.client.GetMulti(keysStr)` and send to channel
    - Select on ctx.Done() (return nil) or channel result
    - Pre-allocate result map with `len(keys)` capacity
    - Iterate `keys` in original ORDER, look up each `keysStr[i]` in `r.items` (Pitfall 1 fix — avoids K-type ambiguity)
    - If item found, `json.Unmarshal(item.Value, &value)`, add to result
    - Silently skip missing keys and deserialization errors (D-06 best-effort)
    - Return result map

    **MSetFunc (per-key goroutines, lines 540-581):**
    - Create buffered channel for results: `make(chan error, len(items))`
    - Resolve TTL once with `c.resolveTTL(ttl...)`
    - Iterate `items`, launch goroutine per key-value pair
    - Each goroutine: `json.Marshal(v)`, build `memcache.Item{Key, Value, Expiration}`, call `c.client.Set(item)`, send error (or nil) to channel
    - Accumulate errors in `var errs []error` via select loop
    - On ctx.Done() during accumulation: return `fmt.Errorf("cache/memcache: %w", ctx.Err())`
    - Return `errors.Join(errs...)` at end

    **MDelFunc (per-key goroutines, lines 584-615):**
    - Create buffered channel: `make(chan error, len(keys))`
    - Iterate keys, launch goroutine per key
    - Each goroutine: call `c.client.Delete(fmt.Sprint(k))`, if `err == memcache.ErrCacheMiss` then send nil (idempotent), else send wrapped error
    - Same select loop for error accumulation with context cancellation
    - Return `errors.Join(errs...)` at end

    Per D-08 (GetMulti for MGet), D-06 (error accumulation via errors.Join).
